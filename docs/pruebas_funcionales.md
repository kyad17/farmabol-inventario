# Pruebas funcionales sugeridas

1. Login como ADMIN:
   - Usuario: admin
   - Contraseña: admin123
   - Resultado esperado: ingresa al dashboard.

2. Login como VENDEDOR:
   - Usuario: vendedor
   - Contraseña: venta123
   - Resultado esperado: puede registrar ventas y consultar stock.

3. CRUD de productos:
   - Crear producto nuevo.
   - Editar precio y stock.
   - Eliminar producto sin ventas.

4. Venta:
   - Seleccionar producto y cantidad.
   - Resultado esperado: se registra la venta y baja el stock.

5. Dashboard:
   - Ver total de ventas del día.
   - Ver productos con stock menor a 5 unidades.
   - Resultado esperado: se actualiza automáticamente cada 5 segundos.
