# Evidencia de calidad estática

Herramienta usada: Pylint.

Comando sugerido:

```bash
pylint app.py
```

También puede guardarse el resultado con:

```bash
pylint app.py > docs/reporte_pylint.txt
```

Captura sugerida para el PDF:
- Terminal mostrando el comando ejecutado.
- Puntaje final de Pylint.
- Advertencias corregidas después de la refactorización.
